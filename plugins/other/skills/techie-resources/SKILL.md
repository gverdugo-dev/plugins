# Techie resources

Una lista de recursos de desarrollo y tecnología que Gonzalo usa o recomienda. Responde
**solo con lo que hay aquí**: cita el recurso con su enlace y su línea de por qué, y di de qué
categoría sale. Si ninguno encaja con lo que se pide, dilo tal cual en vez de inventar uno.

Cada entrada sigue la misma forma: `- [Nombre](url): por qué merece la pena, en una línea.`

## Desarrollo

- [shadcn/ui](https://ui.shadcn.com): componentes de UI que se copian al proyecto en vez de instalarse como dependencia; la base de cualquier front con React y Tailwind.
- [tweakcn](https://tweakcn.com): editor visual de temas para shadcn/ui, con temas ya construidos listos para copiar.
- [Impeccable](https://impeccable.style): plugin de diseño web para Claude Code y otros harnesses; vocabulario, anti-patrones y comandos para que la IA haga interfaces que no parezcan genéricas.
- [Aura gradients](https://auragradients.vercel.app): librería pequeña de fondos con gradientes ambientales en CSS puro, para dar fondo a una web sin imágenes.
- [AI Hero](https://www.aihero.dev): la escuela de Matt Pocock para construir con IA; cursos, cohortes y tutoriales gratuitos.
- [mattpocock/skills](https://github.com/mattpocock/skills): las skills de Matt Pocock para agentes de código; pequeñas y componibles, cubren alinear antes de construir, specs y tickets, TDD, diagnóstico de bugs y revisión. Se instalan como plugin de Claude Code.

## Datos

- [Rill](https://github.com/rilldata/rill): BI de manera agéntica; todo el proyecto son ficheros YAML y SQL (modelos, métricas y dashboards), así que los escribe un agente y se revisan en una PR. Trae plugin oficial de Claude Code con MCP.

## Canales tech

- [midudev](https://www.youtube.com/@midudev): actualidad y desarrollo web en castellano; el canal de referencia para estar al día.
- [ThePrimeagen](https://www.youtube.com/@ThePrimeagen): desarrollo de software del más cracked; rendimiento, herramientas y opinión sin filtro.
- [Coding Jesus](https://www.youtube.com/@CodingJesus): la misma línea que Primeagen; desarrollo serio y crítica de la industria.
- [37signals](https://www.youtube.com/@37signals): el canal de DHH y 37signals; referencia de ideas sobre cómo desarrollar software y dirigir una empresa de producto.
- [CodelyTV](https://www.youtube.com/@CodelyTV): buenas prácticas, arquitectura y testing, en castellano.
- [itnig](https://www.youtube.com/@itnig): actualidad de startups e IA desde Barcelona, en formato podcast en vídeo.
- [Data with Zach](https://www.youtube.com/c/datawithzach): ingeniería de datos con Zach Wilson; pipelines, modelado y cómo se trabaja en equipos de datos grandes.

## Cursos y formación

- [midu.dev](https://midu.dev/cursos): la academia de midudev; cursos de JavaScript, React, Node y TypeScript con proyectos reales, gratuitos y de pago.

## Blogs y webs

- [DHH en HEY World](https://world.hey.com/dhh): los ensayos de DHH sobre desarrollo, producto y cómo trabajar; el complemento escrito al canal de 37signals.

## Newsletters

- [Àlex Rodríguez Bacardit](https://www.alexrodba.com): la newsletter personal del CEO de MarsBased; IA, startups y construir cosas que duren, desde la experiencia de dirigir una consultora de desarrollo.

## Libros

- [Rework](https://basecamp.com/books/rework), de Jason Fried y DHH: cómo construir un producto y una empresa con menos; el libro detrás de las ideas de 37signals.
- [The Data Warehouse Toolkit](https://www.kimballgroup.com/data-warehouse-business-intelligence-resources/books/data-warehouse-dw-toolkit/), de Ralph Kimball: la guía de referencia del modelado dimensional; la base de la ingeniería de datos analítica.
